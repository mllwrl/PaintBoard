# PaintBoard

Бесконечная доска для заметок, схем и рисования — в духе Miro, но локальная: работает без интернета и аккаунта, доска хранится в обычном файле `.pboard`. Написана на Rust; работает в Windows, Linux и macOS, есть пробная веб-версия (WASM).

Ниже — руководство пользователя. Названия кнопок даны так, как они написаны в английском интерфейсе (о русском — в разделе «Язык интерфейса»).

## Установка и запуск

- **Установщик для Windows:** `PaintBoard-<версия>-setup.exe`. Ставит программу для текущего пользователя без прав администратора (можно выбрать «для всех»), добавляет ярлык в меню «Пуск», по желанию — на рабочий стол, и связывает файлы `.pboard` с PaintBoard: двойной щелчок по доске открывает её. Удаляется через «Параметры → Приложения». Рядом с программой лежит `THIRD-PARTY.txt` — лицензии использованных библиотек и шрифта.
- **Из исходников:** `cargo run --release -p pb-app` (в проекте две программы — сама доска и сервер, поэтому `-p` обязателен) или готовый `target\release\paintboard.exe`. Открывается последняя доска; файл, переданный в командной строке (`paintboard.exe доска.pboard`), открывается вместо неё.
- **Одно окно программы:** если PaintBoard уже открыт, повторный запуск (двойной щелчок по доске `.pboard` или плагину `.pbplugin`, ярлык в меню «Пуск») не открывает второе окно: файл передаётся уже открытому, оно выходит на передний план и открывает доску (предложив сохранить текущую безымянную, как обычно) или предлагает установить плагин. Запуск без файла просто показывает открытое окно. Windows иногда не даёт окну выйти вперёд — тогда переключитесь на него через панель задач.
- **Где скачать:** готовые сборки для всех систем — на странице **Releases** репозитория на GitHub. Их собирает workflow `.github/workflows/release.yml`, когда создают тег вида `v0.2.0` (`git tag v0.2.0` и `git push origin v0.2.0`): установщик для Windows, AppImage и архив `.tar.gz` для Linux, образ `.dmg` для macOS.
- **Linux:** `PaintBoard-<версия>-x86_64.AppImage` — один файл, который запускается почти в любом дистрибутиве: `chmod +x PaintBoard-*.AppImage`, затем запустить его. Чтобы появились пункт в меню приложений, значок и открытие `.pboard` и `.pbplugin` двойным щелчком, возьмите архив `PaintBoard-<версия>-linux-x86_64.tar.gz`, распакуйте и выполните `./install.sh` — программа ставится для текущего пользователя в `~/.local/bin` (без sudo); `./install.sh --uninstall` её убирает (доски и настройки остаются). Нужны библиотеки, которые есть почти в любой системе с рабочим столом: ALSA (`libasound2`) и OpenSSL 3; сборка рассчитана на glibc из Ubuntu 22.04 и новее. Доски, настройки и плагины лежат в `~/.local/share/PaintBoard` (или в `$XDG_DATA_HOME/PaintBoard`). Окна выбора файлов показываются через xdg-desktop-portal (есть в GNOME, KDE и большинстве окружений).
- **macOS:** откройте `PaintBoard-<версия>-macos.dmg` и перетащите PaintBoard в «Программы». Сборка работает и на Apple silicon, и на Intel (macOS 11 и новее). Программа не подписана сертификатом Apple и не нотариально заверена (для этого нужен платный аккаунт Apple Developer), поэтому **при первом запуске** щёлкните по ней правой кнопкой (или с Control) → «Открыть» → «Открыть»; на новых macOS может понадобиться «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Дальше она запускается обычно. Файлы `.pboard` и `.pbplugin` связываются с программой, но пока двойной щелчок по ним только запускает PaintBoard — сам файл откройте через **File → Open…** (или перетащите в окно). Доски и настройки — в `~/Library/Application Support/PaintBoard`.
- **Из исходников в Linux и macOS:** нужен Rust (`rustup`); в Linux ещё `pkg-config` и файлы для разработки ALSA и OpenSSL (Debian/Ubuntu: `sudo apt install pkg-config libasound2-dev libssl-dev`), в macOS — Xcode Command Line Tools (`xcode-select --install`). Затем `cargo run --release -p pb-app` или готовый `target/release/paintboard` (`paintboard доска.pboard` открывает файл).
- **Собрать пакеты для Linux:** `sh packaging/linux/build-appimage.sh` (нужен cargo-about, см. ниже, и curl — скрипт сам скачает appimagetool) — AppImage и `.tar.gz` появятся в `target/linux`. **Для macOS:** `sh packaging/macos/build-dmg.sh` на Mac (нужны `rustup target add aarch64-apple-darwin x86_64-apple-darwin` и cargo-about; `UNIVERSAL=0` — только для процессора этого Mac) — образ появится в `target/macos`. В обоих лежит `THIRD-PARTY.txt` с лицензиями.
- **Собрать установщик для Windows:** нужны Inno Setup 6 (`winget install JRSoftware.InnoSetup`) и cargo-about (`cargo install cargo-about --locked --features cli`), затем `powershell -File packaging\windows\build-installer.ps1`. Готовый файл — в `target\installer`.
- **Веб-версия (пробная):** `powershell -File packaging\web\build-web.ps1` собирает её в `target\web` (нужны `rustup target add wasm32-unknown-unknown`, `wasm-bindgen-cli` той же версии, что в `Cargo.lock`, и clang из LLVM). Открывать через любой веб-сервер, например `python -m http.server 8000 --directory target\web`, в браузере с WebGPU (свежие Chrome или Edge). После первого открытия браузер хранит программу у себя: следующий запуск не скачивает её заново и работает без интернета (доски тоже хранятся в браузере). Новая сборка подхватывается при следующей перезагрузке страницы. На Linux и macOS (и в Docker) то же делает `sh packaging/web/build-web.sh [папка]`. Выложить в интернет: в настройках репозитория на GitHub включить «Pages → Source: GitHub Actions» и создать тег вида `v0.2.0` — workflow `.github/workflows/web.yml` соберёт веб-версию и опубликует её как статический сайт. Совместной работе по-прежнему нужен сервер PaintBoard: его адрес вводится в окне «Поделиться».
  - Доски хранятся в самом браузере (на этом сайте и в этом профиле): безымянная доска, сохранённые под именем доски и настройки переживают перезагрузку страницы и закрытие вкладки. Очистка данных сайта в браузере удаляет и доски.
  - «Сохранить как…» спрашивает название и сохраняет доску в браузере. Все сохранённые там доски — в окне «Доски в этом браузере»: оно открывается при запуске веб-версии и из меню «Файл». Щелчок по названию открывает доску; рядом кнопки «Переименовать» (Enter — готово, Esc — отмена), «Скачать» (файл `.pboard`) и «Удалить» (открытую удалить нельзя). Вверху окна — «+ Новая доска» и «Открыть файл…». Esc закрывает окно.
  - «Файл → Скачать доску» скачивает её файлом `.pboard` (например, чтобы открыть в программе для компьютера или перенести в другой браузер). «Открыть…» берёт `.pboard` с компьютера и дальше хранит его в браузере.
  - «Вставить файл…» и перетаскивание файлов в окно браузера работают. Экспорт скачивает файл, печать открывает PDF в новой вкладке (печатать оттуда).
  - Ctrl+V вставляет картинки, ссылки, таблицы и текст из других программ. При первой вставке браузер спрашивает разрешение на чтение буфера обмена — его нужно дать. Ctrl+C в тексте копирует в системный буфер.
  - Пока не работают: звук, распознавание рукописного текста и превью ссылок (карточка ссылки показывает только адрес).
- **Сервер для совместной работы:** `cargo run --release -p pb-server` запускает `paintboard-server`. Настройки задаются переменными окружения: `PB_ADDR` — адрес (по умолчанию `0.0.0.0:8080`), `PB_DB` — файл базы SQLite (по умолчанию `paintboard.db`), `PB_CREATE_KEY` — ключ, без которого нельзя создавать доски (если не задан, создать может любой). `PB_MAX_BOARDS` — сколько досок сервер хранит самое большее; `PB_BACKUP` — папка для ежедневной копии базы (хранятся последние 7). `PB_WEB` — папка собранной веб-версии (`target\web`): тогда сервер раздаёт и её, и ссылка на доску открывается прямо в браузере, без установки программы. С одного адреса можно создать не больше 20 досок в час и держать не больше 16 подключений; за прокси (Caddy) запускайте сервер с `PB_TRUST_PROXY=1`, чтобы он видел адреса клиентов, а не прокси (порт сервера тогда должен быть закрыт для всех, кроме прокси). `PB_METRICS=1` открывает `/metrics` для Prometheus: число досок, открытых досок, подключённых людей, сообщений, отказов и превью (только числа, ничего с самих досок; снаружи этот адрес лучше закрыть в прокси). Схема базы обновляется сама при запуске новой версии сервера; базу от более новой версии старый сервер не откроет. `PB_PREVIEWS=1` включает превью ссылок для веб-версии: браузер сам не может читать чужие сайты, поэтому сервер скачивает за него начало страницы (только `<head>`, только публичные адреса и порты 80/443, не больше 60 страниц в минуту на весь сервер и 20 — с одного адреса). Без этой переменной карточки ссылок в браузере остаются без названия и описания. **Аккаунты** (вход по ссылке из письма, без паролей) включаются, когда серверу есть чем слать письма: `PB_SMTP` — почтовый сервер (`smtps://логин:пароль@smtp.example.com` или `smtp://логин:пароль@smtp.example.com:587?tls=required`), `PB_MAIL_FROM` — от чьего имени письма (`PaintBoard <boards@example.com>`), `PB_PUBLIC_URL` — адрес сервера снаружи для ссылок в письмах (`https://boards.example.com`). Чтобы попробовать без почты, `PB_MAIL=log` пишет письма в журнал сервера вместо отправки. С одного адреса — не больше 10 писем для входа в час, на один email ждут не больше 5 входов сразу. Для работы через интернет сервер ставят за прокси с HTTPS, например Caddy (`packaging/server/Caddyfile`); есть и образ Docker (`packaging/server/Dockerfile`) — в нём сразу и веб-версия, и ежедневные копии базы в `/data/backups`. Как делиться досками — в разделе «Совместная работа».

## Обновления

- Раз в сутки при запуске программа для компьютера в фоне спрашивает GitHub, не вышла ли новая версия (черновики и пре-релизы не в счёт). Без интернета ничего не происходит — ошибки только пишутся в журнал.
- Если вышла, справа вверху появляется заметка «Вышел PaintBoard X» с кнопками:
  - **Обновить** — в Windows скачивает установщик (видно, сколько скачано), проверяет размер файла, сохраняет доску (безымянная сохраняется туда же, откуда восстанавливается при запуске), закрывается и ставит новую версию без вопросов; когда установка закончится, PaintBoard запустится сам. В Linux и macOS открывает страницу выпуска, откуда новую сборку можно скачать.
  - **Что нового** — открывает страницу выпуска в браузере.
  - **Позже** — прячет заметку на сутки (о следующей версии скажет сразу).
- **Вид → Проверить обновления** (или «Проверить обновления» в командной палитре) проверяет сразу и сообщает, если у вас последняя версия.
- **Вид → Проверять обновления каждый день** выключает (и снова включает) автоматическую проверку. Переменная окружения `PB_NO_UPDATE_CHECK=1` тоже её отключает — например, для тестов.
- Версия выпуска берётся из тега (`v0.2.0`), версия программы — из `version` в `Cargo.toml`, поэтому перед созданием тега нужно поднять там версию до той же.

## Доска и файлы

- **Сохранение автоматическое.** Доска с файлом записывается сама вскоре после каждой правки. Безымянная доска хранится в папке программы (`%APPDATA%\PaintBoard\untitled.pboard`), пока её не сохранят под именем.
- **File** (вверху слева): New board (Ctrl+N), Open… (Ctrl+O), Save (Ctrl+S), Save as… (Ctrl+Shift+S), Insert file… (картинки, SVG, PDF, таблицы CSV, Markdown), Diagram from text…, Export… (Ctrl+Shift+E, см. «Экспорт»), Print… (Ctrl+P).
- **File → Read-only** — защитить доску от изменений (сохраняется в файле, рядом с именем доски пишется «read-only»). Остаются только выделение, копирование, комментарии, реакции, голосование, поиск и презентация; Ctrl+Z не работает. Выключается тем же пунктом.
- **Frames** — список фреймов доски, щелчок переносит к фрейму.
- **Present** (F5) — показ фреймов по очереди (см. «Презентация»).
- **Talktracks** — запись голоса с прогулкой по доске (см. «Talktrack»).
- **History** — версии доски (см. «История версий»).
- **Vote** — голосование (см. «Голосование»).
- **Timer** — обратный отсчёт на 1–30 минут или на своё время (в меню ввести минуты, `1,5`, `2:30` или `1:00:00`, затем Enter или «Запустить»; до 24 часов): табло вверху по центру с паузой, перезапуском и закрытием; по окончании мигает «Time's up». Виден и во время презентации. Таймер хранится в доске: на общей доске его видят все, и пауза или перезапуск у одного видны у всех; Ctrl+Z его не трогает. Через 10 минут после окончания табло пропадает само. По ссылке для просмотра таймер виден, но управлять им нельзя. Когда время выходит, у каждого участника один раз звучит короткий сигнал (не звучит, если таймер на паузе или если доску открыли уже после окончания); выключается галочкой **«Звук, когда время вышло»** в меню таймера — только на этом компьютере. В браузере звук может не прозвучать, пока вы ни разу не щёлкнули по странице.
- **Templates** — готовые заготовки (см. ниже).
- **Filter** — показать только объекты с выбранными тегами или цветами (остальное бледнеет). Здесь же можно перекрасить или удалить тег.
- **Comments** — все обсуждения доски (в скобках — сколько открытых); Show resolved — показывать и решённые.
- **Find** (Ctrl+F) — поиск текста по доске.
- **Commands** (Ctrl+K) — командная палитра (см. «Командная палитра»).
- **?** (F1) — окно со списком горячих клавиш.

## Совместная работа

Нужен сервер PaintBoard (см. «Установка и запуск»): свой или чей-то, кому вы доверяете.

- **Поделиться доской:** кнопка «Поделиться» справа в верхней панели → введите адрес сервера (например, `boards.example.com` или `http://localhost:8080`) → «Поделиться этой доской». Доска выкладывается на сервер, в окне появляются три ссылки: **для правки**, **для комментариев** и **для просмотра**. Кнопка «Копировать» кладёт ссылку в буфер обмена — отправьте её тем, с кем работаете.
- **Ссылка в браузере:** если сервер раздаёт веб-версию (`PB_WEB`), ссылку можно просто открыть в Chrome или Edge — доска откроется сразу и будет храниться в этом браузере под своим названием (пока оно не пришло с сервера — под номером). Переименованная доска по той же ссылке открывается как прежде.
- **Ваше имя:** поле «Ваше имя» в окне «Поделиться». Его видят другие рядом с вашим указателем, комментариями, голосами, реакциями и записями Talktrack.
- **Открыть чужую доску:** «Поделиться» → вставьте ссылку в поле «Или откройте доску, которой с вами поделились» → «Открыть». Текущая доска закрывается (безымянную программа предложит сохранить).
- Пока доска общая, правки всех видны сразу. Цветные стрелки с именами — указатели других участников, цветные рамки — то, что у них выделено. На кнопке в верхней панели — сколько человек на доске сейчас (зелёная точка — на связи).
- **Следить за участником:** «Поделиться» → щёлкните имя в строке «Сейчас здесь» — ваш вид плавно повторяет его вид (по краю экрана цветная рамка, сверху плашка). Перестать — Esc, кнопка на плашке или просто сдвиньте доску сами.
- **Собрать всех у себя:** кнопка в окне «Поделиться» — все на доске начинают следить за вашим видом (удобно для показа). Кто сдвинет доску сам, перестаёт следить. «Перестать вести» — на плашке сверху.
- Одновременные правки не теряются: если двое правят один стикер, ячейку таблицы, карточку канбана, узел майнд-карты, подпись стрелки или заголовок карточки ссылки, сохраняется текст обоих — даже если один ещё печатает. Если объект, который вы правите, в это время передвинули, изменили его размер или перенесли карточку в другую колонку, поле правки идёт вместе с ним, и после правки это не откатывается. Ctrl+Z отменяет только ваши правки.
- По ссылке для просмотра доску можно смотреть, но не менять.
- По ссылке для комментариев доску тоже нельзя менять, но можно оставлять комментарии, отвечать на них, ставить реакции и голосовать (когда голосование запущено). Без связи с сервером комментировать нельзя: комментарии сразу уходят на сервер. Если в вашей копии были свои правки, которых нет на сервере, при входе по такой ссылке копия становится такой же, как на сервере. Сервер сам проверяет, что по этой ссылке приходят только комментарии, реакции и голоса.
- Если связь пропала, программа переподключается сама, а ваши правки отправятся, когда связь вернётся. «Повторить» в окне — переподключиться сразу.
- «Перестать делиться» — дальше работать с этой копией одному. Копия доски хранится и у вас (в её файле или как безымянная), даже пока она общая.
- Программа помнит, какая доска общая: при следующем открытии (и после перезапуска) она снова подключается сама. «Перестать делиться» это забывает.

### Аккаунт

Если на сервере включены аккаунты (см. «Установка и запуск»), в окне «Поделиться» появляется вход. Паролей нет: вход — по ссылке из письма.

- **Войти:** введите email → «Войти». На почту придёт письмо со ссылкой; в программе показан короткий код — он же на странице, которая откроется по ссылке. Если коды совпадают, нажмите там «Войти» — программа войдёт сама через пару секунд. Ссылка работает 15 минут и один раз; открыть её можно и на телефоне.
- **Мои доски:** после входа в окне «Поделиться» — список досок аккаунта (ваши и те, к которым вам открыли доступ), с вашей ролью. Щелчок по названию открывает доску. «Обновить» — перечитать список.
- Доска, которой вы поделились после входа, — ваша (вы её владелец). Для неё в окне «Поделиться» есть:
  - **Доступ по email:** введите адрес, выберите «может править», «может комментировать» или «может смотреть» → «Открыть доступ». Человеку придёт письмо; войдя с этим адресом, он найдёт доску в «Мои доски». Роль меняется в списке, × убирает доступ.
  - **Новая ссылка** у каждой ссылки — делает новую, старая перестаёт работать (если ссылка ушла не туда).
  - **Удалить с сервера…** — доска пропадает у всех (с подтверждением); ваша копия на компьютере остаётся.
- Ссылка без ключа (`…/board/<id>`) открывает доску только тем, у кого есть доступ по аккаунту. Если у человека есть и ссылка, и доступ по аккаунту, действует то, что позволяет больше.
- **Выйти** — забыть вход на этом компьютере. **Удалить аккаунт…** — удаляет аккаунт и все доски, владельцем которых он был, с сервера у всех (с подтверждением). Копии досок, открытых на этом компьютере, остаются; чтобы сохранить остальные, сначала откройте их из «Мои доски».

## Плагины

Плагины добавляют программе свои команды и окна. Плагин — это папка с файлом `manifest.json` и скриптом на JavaScript; он работает в отдельной «песочнице» и видит доску только через то, что ему разрешено.

- **Plugins** в верхней панели — команды установленных плагинов; **Manage plugins…** — окно управления. Команды, рассчитанные на выделенное, есть и в меню правой кнопки над выделенными объектами (наверху списка).
- **Установить плагин:** плагин обычно передают одним файлом `.pbplugin`. Его можно открыть двойным щелчком (после установки программы через установщик), перетащить в окно программы или выбрать в окне управления: **Install plugin…**. Там же можно выбрать `manifest.json` плагина-папки (в браузере — `manifest.json` вместе со скриптами, несколько файлов сразу). Перед установкой программа показывает, что плагин сможет делать: читать доску, менять доску, загружать с указанных сайтов, класть текст в буфер обмена. Плагин с тем же id заменяет прежний.
- В окне у каждого плагина: флажок «включён», описание, права, **Remove** (удалить вместе с тем, что он хранит) и **Log** — журнал его сообщений и ошибок. Если плагин завис (работал дольше 2 секунд подряд) или упал, он останавливается, а причина видна красным; запустить снова — снять и поставить флажок.
- Всё, что плагин меняет по одной команде, отменяется одним Ctrl+Z. На общей доске правки плагина видят все, ставить его нужно только тому, кто им пользуется.
- Сообщения плагинов на короткое время появляются внизу окна; окна плагинов открываются справа. Плагины могут проигрывать короткие встроенные звуки (сигнал, звон) и ждать заданное время — для этого прав не нужно.
- Плагины с правом менять доску могут создавать таблицы и заполнять их ячейки, ставить метки (и заводить новые), подписывать коннекторы, добавлять объектам ссылки, группировать и разгруппировывать объекты.
- Ставьте плагины только от тех, кому доверяете: плагин с правом менять доску может изменить или удалить на ней что угодно. В программе для компьютера у плагинов нет доступа к файлам, сети и системе вообще (только то, что разрешено через программу); в браузере изоляция слабее.

**Примеры** лежат в `packaging/plugins/examples`: «Number stickies» (нумерует выделенные стикеры), «Stickies by color» (раскладывает стикеры по цветам в столбцы), «Quick notes» (окно, где каждая строка становится стикером), «Table from CSV» (вставленный CSV или ячейки из Excel превращаются в таблицу; можно и загрузить CSV-файл с GitHub по адресу), «Countdown» (обратный отсчёт на заданное число минут со звонком в конце).

**Писать свои плагины:** в окне управления **Develop from a folder…** (только в программе для компьютера) → выберите `manifest.json` своего плагина. Он работает прямо из своей папки и перезапускается каждый раз, когда вы сохраняете его файлы. Кнопка **Pack…** у такого плагина сохраняет его одним файлом `.pbplugin`, чтобы передать другим (подойдёт и обычный zip папки плагина с расширением, переименованным в `.pbplugin`). Описание API для авторов (на английском) — `packaging/plugins/README.md`, типы для TypeScript — `packaging/plugins/paintboard.d.ts`. Коротко:

```js
// main.js
paintboard.ui.addCommand({ id: "hello", title: "Say hello" }, async () => {
  const [id] = await paintboard.board.create({ type: "sticky", text: "Hello!" });
  await paintboard.board.select(id);
});
```

```json
{ "id": "me.hello", "name": "Hello", "version": "1.0.0", "api": 1,
  "permissions": ["board:write"], "main": "main.js" }
```

## Экспорт

**File → Export…** (Ctrl+Shift+E) сохраняет картинку, векторный рисунок (SVG), PDF, текст или таблицу:

- **What** — Whole board (всё видимое на доске), Selection (выделенное; у фрейма — вместе с содержимым) или Frame (то, что внутри выбранного фрейма, обрезанное по его краю). Для PDF есть ещё All frames, a page each — все фреймы, каждый на своей странице, в порядке меню Frames. Если перед открытием что-то выделено, сразу выбрано Selection.
- **Format** — PNG, JPEG, SVG, PDF или PDF (pictures). **SVG** и **PDF** — векторные: фигуры, линии, коннекторы со стрелками, рисунки пером, стикеры, фреймы, таблицы, канбан, майнд-карты и документы остаются линиями и заливками и чёткие при любом увеличении; картинки вставлены как есть. Текст записан контурами букв (шрифт Inter), поэтому выглядит и переносится точно как на доске, даже где Inter не установлен, но выделить и скопировать его в файле нельзя. Тень стикера в PDF нарисована упрощённо. **PDF (pictures)** — прежний вариант: каждая страница — картинка, как на экране. Размер страницы PDF соответствует доске: 96 единиц доски на дюйм; SVG — единица доски на пиксель. **Size** — 1×…4× (1× — как доска при масштабе 100%; для PDF (pictures) — чёткость); для SVG и PDF не нужен. **Transparent background** — PNG или SVG без фона (иначе фон белый).
- **Markdown** — текст выбранного: имя доски заголовком, фреймы — разделами, тексты, стикеры и фигуры — списком (сверху вниз, слева направо), таблицы — таблицами Markdown, канбан — колонками с карточками, майнд-карты — вложенными списками, Markdown-документы — как есть. Картинки, рисунки и линии пропускаются.
- **CSV** — первая (самая верхняя) таблица выбранного, для Excel и Google Таблиц.
- Сетка, рамки выделения, значки голосования и скрытые объекты на картинку не попадают; фильтр и режим фокуса не бледнят объекты. Очень большие картинки уменьшаются до 16384 пикселей по длинной стороне.

## Печать

**File → Print…** (Ctrl+P) делает векторный PDF — по странице на каждый фрейм (в порядке меню Frames), а если фреймов нет, одну страницу со всей доской — и открывает его в программе для PDF (в Windows обычно Edge), откуда его печатают. Файл лежит во временной папке (`%TEMP%\PaintBoard`; в Linux и macOS — папка `PaintBoard` во временной папке системы, обычно `/tmp` или `$TMPDIR`).

## История версий

- **History → Save version** — запомнить доску как она есть сейчас (имя можно ввести в поле, иначе «Version N»). Версии хранятся в файле доски вместе с картинками, которые в них были, даже если на доске их уже удалили. Сохранять версии можно и на доске только для чтения.
- Щелчок по версии в списке показывает доску такой, какой она была. Вверху — имя, кто и когда сохранил, сколько объектов изменено, удалено и добавлено с тех пор; изменённые и удалённые обведены. В этом режиме можно только смотреть (колесо — прокрутка, Ctrl + колесо — масштаб, средняя кнопка — сдвиг).
- **Restore** — вернуть доску к этой версии (Ctrl+Z отменяет возврат целиком; список версий не меняется). **Close** или Esc — обратно к доске.
- **×** рядом с версией — забыть её (с подтверждением, не отменяется).

## Навигация

- **Перемещение:** колесо мыши (вверх-вниз), Shift + колесо (влево-вправо), пробел + перетаскивание, средняя кнопка мыши, прокрутка тачпадом.
- **Доска едет сама,** если тащить объект, угол, рамку выделения или конец коннектора к краю окна (или за край): чем ближе к краю, тем быстрее, а перетаскиваемое едет вместе с ней.
- **Масштаб:** Ctrl + колесо мыши, Ctrl + прокрутка тачпада, щипок, Ctrl+= / Ctrl+−, кнопки − / + внизу справа; Ctrl+0 — 100 %; Home — к началу доски.
- **Закладки вида:** Ctrl+Shift+1…9 запоминает, что сейчас на экране (место и масштаб), под номером 1…9 — появится «Вид 3 сохранён»; Ctrl+1…9 плавно переносит к сохранённому виду. Закладки хранятся в самой доске: на общей доске они общие для всех, работают и на доске только для чтения, а Ctrl+Z их не трогает. То же есть в командной палитре: «Перейти к виду N» и «Сохранить вид как N».
- **Внизу справа:** Dots — вид сетки (точки, линии, без сетки; клавиша G), Snap to grid — привязка к сетке (Shift+G), Map — мини-карта (щелчок или перетаскивание по ней переносит вид).


## Перо и сенсорный экран

- **Перо** рисует выбранным инструментом и чувствует нажим (ручка и маркер).
- **Обратная сторона пера (ластик)** стирает штрихи, какой бы инструмент ни был выбран; выбранный инструмент при этом не меняется — переверните перо обратно, и оно снова рисует. Пока перо перевёрнуто и висит над экраном, виден кружок ластика.
- **Боковая кнопка пера:** штрих с зажатой кнопкой тоже стирает; касание с зажатой кнопкой без движения открывает контекстное меню, как правый щелчок мыши.
- **Защита от ладони:** пока перо рядом с экраном или касается его (и ещё полсекунды после), касания пальцами и ладонью ничего не делают — не рисуют, не выделяют и не двигают.
- **«Перо рисует, пальцы двигают доску»** (меню «Вид» внизу справа или командная палитра): один палец двигает доску, два — масштабируют и двигают её; пальцы при этом никогда не рисуют. Включается само, как только на компьютере впервые используется перо; выбор запоминается. Если выключено, первый палец работает как мышь (как на сенсорном экране без пера).
- В веб-версии всё то же самое работает в браузерах, которые сообщают о пере (Chrome, Edge): ластик, боковая кнопка, защита от ладони и навигация пальцами.


## Командная палитра

Ctrl+K (или Ctrl+Shift+P, или кнопка **Commands** в меню) открывает поле вверху по центру: начните печатать — ниже останется то, что подходит.

- **Команды меню и инструменты:** новая доска, открыть, сохранить, экспорт, печать, отмена и повтор, выделить всё, группировка, блокировка, презентация, поиск, шаблоны, голосование, таймер на 5 или 10 минут, запись, сохранить версию, масштаб (в том числе Zoom to fit — показать всё, не крупнее 100 %), сетка, мини-карта, слои, тема, язык и т. д.; справа — горячая клавиша. Недоступное сейчас (например, правка на доске только для чтения или группировка без выделения) не показывается.
- **Фреймы:** «Go to frame: …» — перейти к фрейму по заголовку.
- **Закладки вида:** «Go to view N» — к сохранённому виду, «Save view as N» — сохранить текущий (см. «Навигация»).
- **Текст на доске:** от двух букв — до пяти объектов с этим текстом (стикеры, фигуры, ячейки, карточки, темы…); выбор показывает объект, как поиск.
- **Команды плагинов** — с именем плагина.

Ищется без учёта регистра по началу слов и по части названия, и по-русски, и по-английски (в русском интерфейсе можно набрать `save` или `zoom`). Пока ничего не набрано, сверху — последние пять запущенных команд (помнятся и после перезапуска программы; то, чего больше нет, просто не показывается). ↑ / ↓ или Tab / Shift+Tab — выбор, Enter или щелчок — выполнить, Esc, Ctrl+K или щелчок мимо — закрыть.

## Язык интерфейса

- Интерфейс бывает на русском и английском. Кнопка **RU / EN** в панели внизу справа переключает язык; выбор запоминается. При первом запуске язык берётся из настроек системы (русский — если система на русском, иначе английский).
- В этом руководстве названия кнопок и меню даны по-английски, как в английском интерфейсе; в русском они переведены (например, File — «Файл», Export… — «Экспорт…»).

## Размер интерфейса и контраст

- **View** (в панели внизу справа) → **Interface size**: 75–200% — меню, панели и окна становятся крупнее или мельче, доска при этом не меняется. То же с клавиатуры: Ctrl+Alt+= / Ctrl+Alt+− / Ctrl+Alt+0 (Ctrl+= и Ctrl+− по-прежнему масштабируют доску).
- **View → High contrast** — чёрный (в тёмной теме белый) текст и чёткие рамки у кнопок и панелей.
- Если панель инструментов слева не помещается по высоте, её можно прокрутить колесом. Оба выбора запоминаются.

## Во весь экран и чистая доска

- **F11** (или **View → Full screen**) — окно на весь экран; ещё раз F11 — обратно.
- **`Ctrl+\`** (или **View → Clean board**) — чистая доска: все панели скрываются, остаётся только маленькая кнопка « в правом нижнем углу, которая (как и `Ctrl+\`) возвращает их. Панели выделения и текста, окна и меню по правому щелчку при этом работают как обычно.
- Панели можно скрывать и по отдельности: маленькая стрелка в конце меню доски, внизу панели инструментов и в конце нижней панели, или **View → Panels**. На месте скрытой панели остаётся кнопка », которая её возвращает. Какие панели скрыты, запоминается.

## Цвет доски

- **View → Board color** — фон доски: обычный или один из спокойных цветов. Цвет хранится в самой доске (его видят все, кто её открывает, он попадает в экспорт и печать), Ctrl+Z отменяет. В тёмной теме вместо самого цвета — его тёмный оттенок.

## Тёмная тема

- Кнопка **Dark** в панели внизу справа включает и выключает тёмную тему; выбор запоминается. При первом запуске тема берётся из настроек системы.
- В тёмной теме тёмные линии и текст, лежащие прямо на доске (перо, коннекторы, текст и фигуры без заливки), рисуются светлыми, белые фреймы — тёмными. Стикеры, таблицы, карточки и цвета, выбранные вручную, не меняются.
- Экспорт и печать всегда в светлой теме.
## Инструменты (панель слева)

| Кнопка | Клавиша | Что делает |
|---|---|---|
| Выделение | V | Выбор, перемещение, изменение размера |
| Фигуры | R, O, S | Прямоугольник (R), эллипс (O), S — перебор основных фигур |
| Ручка, маркер, ластик | P, M, E | Рисование от руки (нажим пера учитывается), полупрозрачный маркер, ластик целых штрихов |
| Текст | T | Щелчок — новый текст |
| Стикер | N | Щелчок — новый стикер (цвет выбирается в панели рядом) |
| Коннектор | L | Линия между объектами |
| Фрейм | F | Протянуть или щёлкнуть — фрейм |
| Таблица | — | Протянуть или щёлкнуть — таблица 3×3 |
| Канбан | K | Щелчок — доска с колонками To do / In progress / Done |
| Майнд-карта | — | Щелчок — карта с центральной темой |
| Документ | D | Щелчок — страница с текстом в Markdown |
| Комментарий | C | Щелчок по объекту или по доске — начать обсуждение |
| Изображение | — | Выбрать файлы картинок |

Фрейм, таблица, канбан, майнд-карта и документ делят одну кнопку: на ней значок последнего выбранного из них, а пока он включён, рядом открывается панель со всеми пятью.

Фигуры, текст, стикеры и т. п. — «одноразовые» инструменты: после создания объекта снова включается выделение. С зажатым Shift ручка и маркер рисуют прямую линию от места, где Shift нажат, одной толщины по всей длине; почти горизонтальная или почти вертикальная (в пределах 8°) линия выравнивается точно. Отпустите Shift — линия продолжится от руки. Ручка и маркер остаются включёнными, курсор у них — точка цвета и толщины линии, а выделение при их выборе снимается; их панель цвета и толщины прячется, как только начинаете рисовать, и снова открывается щелчком по кнопке инструмента.

## Выделение и правка

- **Выделить:** щелчок; рамкой по пустому месту; Shift или Ctrl + щелчок — добавить/убрать; Ctrl+A — всё.
- **Двигать:** перетаскивать, стрелки (с Shift — шаг больше). Alt + перетаскивание — копия.
- **Размер и поворот:** 8 ручек по краям (с Shift — сохранить пропорции), ручка над рамкой — поворот (с Shift — шаг 15°).
- **Умные направляющие** показывают выравнивание по соседям при перетаскивании и при изменении размера (в том числе картинок и с сохранением пропорций — тогда прилипает та сторона, что ближе); Ctrl при перетаскивании отключает привязку. У повёрнутых объектов привязки при изменении размера нет.
- **Раскладка:** выделите несколько объектов → **Arrange** на панели: Grid — сеткой в порядке чтения (Alt+G), By color — группами по цвету заливки, By tag — группами по тегу; у каждой группы появляется заголовок. Одним Ctrl+Z отменяется.
- **Выравнивание:** Alt+A / Alt+D — по левому / правому краю, Alt+W / Alt+S — по верху / низу, Alt+H / Alt+V — по центру по горизонтали / вертикали; Alt+Shift+H / Alt+Shift+V — распределить равномерно.
- **Буфер:** Ctrl+C / Ctrl+X / Ctrl+V, Ctrl+D — дублировать, Delete — удалить (если удаляется больше 20 объектов или вся доска, программа сначала спросит). Картинки можно вставлять из буфера и перетаскивать файлами в окно.
- **Порядок слоёв:** Ctrl+] / Ctrl+[ — на шаг выше/ниже, с Shift — наверх/вниз.
- **Группы и блокировка:** Ctrl+G — сгруппировать, Ctrl+Shift+G — разгруппировать, Ctrl+Shift+L — заблокировать/разблокировать.
- **Скрыть:** Ctrl+Shift+H или **Hide** на панели — объект пропадает с доски, миникарты и из поиска и не выделяется (сохраняется в файле, отменяется Ctrl+Z). Внизу справа появляется **Hidden (N)**: включите его, чтобы видеть скрытые бледными, выделите нужные и нажмите **Show** (или снова Ctrl+Shift+H).
- **Отмена:** Ctrl+Z, повтор — Ctrl+Y или Ctrl+Shift+Z.
- **Esc** отступает на шаг: отменяет текущее действие, затем выключает инструмент, затем снимает выделение.

**Панель над выделением** показывает то, что подходит выделенному: заливку, цвет обводки и толщину, «Aa» — цвет, размер и выравнивание текста в фигурах, прозрачность, Link, Tags, Lock, Hide, Front / Back, Duplicate, Delete и кнопки, особые для таблиц, канбана, майнд-карт, коннекторов и картинок.

**Правый щелчок** открывает меню: правка текста, вырезать / копировать / вставить, дублировать, удалить, порядок, группировка, блокировка, скрытие, ссылка на объект, режим фокуса. На пустом месте — вставить сюда, добавить стикер или текст сюда, выделить всё, фокус на видимой части.

## Текст

- Новый текст — инструмент T; правка — двойной щелчок или Enter на выделенном объекте. Esc или щелчок мимо — закончить.
- Внутри правки: Ctrl+B / I / U — жирный, курсив, подчёркнутый, Ctrl+Shift+X — зачёркнутый; панель над текстом — те же кнопки и цвет фрагмента. Работают выделение мышью, буфер обмена, отмена внутри правки, ввод через IME.
- Текст в фигурах вписывается в фигуру и уменьшается, если не помещается. Цвет, размер и выравнивание — кнопка «Aa».
- **Стикеры** сами подбирают размер шрифта. Tab — новый стикер справа, Shift+Tab — снизу.

## Шаблоны

Кнопка **Templates** вверху открывает галерею: SWOT-анализ, ретроспектива, канбан, дорожная карта (таблица по кварталам), карта пользовательских историй, карта пути клиента (таблица), брейнрайтинг 6-3-5, майнд-карта и блок-схема. Щелчок по карточке ставит шаблон в середину вида и показывает его целиком; всё вставленное выделено и убирается одним Ctrl+Z. Шаблоны собраны из обычных объектов — фреймов, стикеров, фигур, таблиц, — их можно править как угодно.

## Фигуры и наборы для диаграмм

Новые фигуры рисуются без заливки (только контур); залить их можно кнопкой заливки на панели выделения. Щелчок внутри прозрачной фигуры всё равно её выделяет.

Кнопка фигур открывает панель с наборами:

- **Basic** — прямоугольник, скруглённый, эллипс, ромб, треугольник, звезда, стрелки, облако, шестиугольник, параллелограмм, трапеция.
- **Flowchart** — начало/конец, процесс, решение, данные, документ, предопределённый процесс, ручной ввод, ручная операция, подготовка, база данных, задержка, переход на другую страницу.
- **UML** — класс, актёр, вариант использования, состояние, заметка, пакет.
- **Entity relationship** — сущность, связь, атрибут, таблица.
- **BPMN** — задача, событие, шлюз, объект данных, хранилище данных, пул.
- **Network** — сервер, компьютер, база данных, облако, пользователь.

Щелчок ставит фигуру в её естественных пропорциях, протяжка — любого размера (с Shift — квадратную).

## Коннекторы

- Инструмент L: протянуть от объекта к объекту. Конец «прилипает» к точкам соединения или к контуру и следует за объектом.
- На панели: Straight / Elbow / Curved (прямая, ломаная, кривая), стрелки на концах, Reset path.
- Ломаные сами обходят другие объекты. Изгибы можно двигать за ручки на отрезках.
- Подпись: двойной щелчок по линии или Enter; подпись можно тащить вдоль линии.
- **Быстрое создание:** у выделенной фигуры или стикера появляются точки «+» — щелчок создаёт копию рядом, соединённую стрелкой, и сразу открывает её текст.

## Фреймы

- Инструмент F. Объекты, центр которых внутри фрейма, принадлежат ему: двигаются и копируются вместе с ним.
- Выделяется фрейм за заголовок; двойной щелчок по заголовку — переименовать.
- Меню **Frames** — переход к фрейму.

## Презентация

- **Present** вверху или F5: фреймы показываются по одному во весь экран, в порядке меню Frames; всё вокруг затемнено, панели скрыты.
- Следующий фрейм — →, ↓, пробел, PageDown или Enter; предыдущий — ←, ↑, PageUp или Backspace; Home / End — первый / последний. Внизу — кнопки ◀ ▶ и номер слайда.
- Во время показа доску нельзя случайно изменить; Ctrl + колесо приближает, колесо и средняя кнопка двигают.
- **Laser** на панели или клавиша L — лазерная указка: вместо курсора красная точка с затухающим следом.
- Esc, F5 или Exit — закончить: вид вернётся туда, где был.

## Слои

- **Layers** внизу справа открывает панель слоёв (сверху — верхний слой). Объекты верхнего слоя всегда лежат поверх объектов нижних; Ctrl+] / Ctrl+[ меняют порядок внутри слоя.
- **+ Add** — новый слой сверху. Щелчок по слою делает его текущим: новые объекты, вставка и рисование пером попадают в него. Двойной щелчок — переименовать.
- Галочка слева — показать/скрыть слой целиком; **Lock** — заблокировать всё на слое; ↑ / ↓ — поднять или опустить слой; **×** — удалить слой вместе со всем, что на нём (Ctrl+Z вернёт). Нижний слой «Layer 1» удалить нельзя.
- Если слоёв больше одного, на панели выделения есть **Layer** — перенести выделенное на другой слой.

## Режим фокуса

- Shift+F или правый щелчок → **Focus on selection**: вид приближается к выделенному, остальная доска почти исчезает и перестаёт откликаться на щелчки, рамку выделения, Ctrl+A и ластик. Без выделения (правый щелчок по пустому месту → **Focus on this view**) в фокусе остаётся то, что сейчас на экране.
- В фокусе — объекты, центр которых внутри выбранной области (как у фреймов); новые объекты внутри неё тоже. Меню доски и миникарта на это время скрыты, инструменты и правка работают как обычно.
- Выход — Esc (когда ничего не выделено), Shift+F или **Exit** вверху; вид вернётся туда, где был.

## Talktrack

- **Talktracks → ● Record talktrack** начинает запись: голос с микрофона, движение вида (прокрутка, масштаб, переходы по фреймам, презентация) и указатель мыши. Внизу слева — красная точка, время, **Stop** (сохранить) и **Cancel** (выбросить). Без микрофона записывается только движение — так и написано: «no microphone». В веб-версии браузер сначала спрашивает разрешение на микрофон; если запретить, запись пойдёт без звука.
- Записи хранятся в доске (звук сжат, около 0,5 МБ в минуту) и перечислены в меню Talktracks: щелчок по записи проигрывает её, **×** удаляет.
- При проигрывании вид сам повторяет запись, указатель показан красной точкой, панели скрыты. Внизу: Play/Pause (пробел), ползунок перемотки, время, Exit (Esc); ← / → — на 5 секунд назад/вперёд. После выхода вид возвращается.
- Записывать и проигрывать можно и в режиме только для чтения. В браузерной версии звука пока нет.

## Голосование

- **Vote** вверху → выберите число голосов на человека (3, 5 или 10) — начнётся голосование. Внизу видно, сколько голосов осталось.
- Пока идёт голосование, щелчок по объекту отдаёт ему голос (можно несколько), Shift+щелчок забирает один обратно; на объектах — синие кружки с вашими голосами. Доска в это время щелчками не правится.
- **End voting** заканчивает: на объектах появляются общие числа, три лучших — золотые, открывается окно результатов (щелчок по строке переносит к объекту). В меню Vote — Results (окно снова), Clear votes (убрать голоса) и новое голосование.

## Таблицы

- Двойной щелчок по ячейке — правка; Tab / Shift+Tab — следующая / предыдущая ячейка.
- Линии между строками и столбцами можно тащить, меняя их размер.
- Щелчок по ячейке выделенной таблицы выделяет ячейку, протяжка или Shift+щелчок — блок ячеек. Тогда на панели: Row ↑ / Row ↓ / Column ← / Column → (вставить рядом), Delete rows / Delete columns, Merge / Unmerge (объединить ячейки). Ctrl+щелчок, как в Проводнике, добавляет ещё ячейку (а протяжка после него — ещё блок), Ctrl+щелчок по выделенной ячейке убирает её; объединять можно только один блок. Delete очищает текст выделенных ячеек, Ctrl+B / I / U (и Ctrl+Shift+X) делают весь их текст жирным, курсивом, подчёркнутым (зачёркнутым) или снимают это, Enter правит первую, Esc снимает выделение ячеек.
- Без выделенных ячеек: + Row, + Column, − Row, − Column.
- **Из CSV:** перетащите файл `.csv` / `.tsv` в окно или выберите его в File → Insert file… — получится таблица, столбцы подогнаны под текст. Разделитель (запятая, точка с запятой или табуляция) определяется сам, ячейки в кавычках могут содержать разделители и переносы строк. Ячейки, скопированные из Excel или Google Таблиц, вставляются таблицей по Ctrl+V. Больше 500 строк и 50 столбцов не берётся.

## Канбан

- Инструмент K ставит доску с тремя колонками.
- Выделите доску: «+ Add card» в колонке — новая карточка (пустая не сохранится); Tab в карточке — следующая под ней.
- Карточки перетаскиваются между колонками и внутри колонки сразу, без выделения доски; сама доска двигается за заголовки колонок и фон. Щелчок выделяет карточку: Delete — удалить, Enter — править.
- Двойной щелчок по заголовку колонки — переименовать. + Column / − Column на панели.

## Майнд-карты

- Инструмент «Mind map»: щелчок ставит карту, центральная тема сразу открыта для ввода.
- Во время ввода: Tab — подтема, Enter — следующая тема того же уровня, Shift+Enter — перенос строки, Esc — закончить.
- Выделите карту и щёлкните тему: Tab / Enter — добавить, F2 или двойной щелчок — править, Delete — удалить тему с подтемами (центральная — всю карту). На панели: + Child, + Sibling, Collapse / Expand, Delete topic.
- Кружок рядом с темой сворачивает ветку; у свёрнутой показано число скрытых тем. Раскладка автоматическая, новые главные темы ложатся на более свободную сторону.

## Документы (Markdown)

- Инструмент «Markdown document» (клавиша D): щелчок ставит страницу с примером, он сразу выделен — начните печатать, чтобы заменить его.
- Пока документ правится, виден исходный текст Markdown. Esc или щелчок мимо — страница показывает оформленный текст и сама подстраивает высоту. Ширину меняют ручками.
- Двойной щелчок или Enter — снова править.
- Поддерживается: заголовки `#`, `##`, `###`; абзацы (пустая строка между ними); списки `-`, `*`, `+` и `1.` (вложенность — два пробела); цитаты `>`; блоки кода между строками из трёх обратных апострофов; линия `---`; в тексте — `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``, `[ссылка](адрес)`; обратная косая черта перед символом показывает его как есть.
- Файлы `.md`, `.markdown` и `.txt`, перетащенные в окно, становятся документами.
- Текст документов находит поиск (Ctrl+F).

## Диаграмма из текста (Mermaid)

File → **Diagram from text…** — вставить блок-схему в синтаксисе Mermaid и нажать Insert. Пример:

```
flowchart TD
    A([Start]) --> B[Write the plan]
    B --> C{Looks good?}
    C -->|yes| D[Build it]
    C -->|no| B
    D --> E[(Save)]
```

Поддерживаются направления TD / BT / LR / RL; узлы `[ ]`, `( )`, `([ ])`, `[( )]`, `(( ))`, `{ }`, `{{ }}`, `[/ /]`, `> ]`; линии `-->`, `---` (без стрелки), `==>` (толстая), `-.->` (пока рисуется сплошной); подписи `-->|текст|` и `-- текст -->`; цепочки `A --> B --> C` и `A & B --> C`; комментарии `%%`. Ошибки показываются с номером строки.

## Графики функций

- **File → Graph of a function…** — формула от x и диапазон x: `sin(x)`, `x^2 - 3x + 1`, `1/x`, `sqrt(x)`, `|x|`, `2^x`, `ln(x)`; несколько формул — через `;`, каждая своим цветом. Можно писать `2x`, `3sin x`, `x²`, `√x`, `π`, `e`, `tg`, `ctg`, `lg`, десятичную запятую, а также `y = …`.
- На доску в середину экрана встаёт группа: белое поле с сеткой и подписями делений, оси, кривые и формулы над полем. Масштаб по y подбирается сам, выбросы у разрывов (как у `tan` или `1/x`) отрезаются. Группу можно двигать, масштабировать и разгруппировать.

## Изображения

- Вставка: кнопка на панели или File → Insert file…, перетаскивание файлов в окно, Ctrl+V из буфера.
- **SVG** (и сжатые `.svgz`) ставятся картинкой в своём размере, отрисованной с запасом чёткости; текст в них рисуется системными шрифтами. Править фигуры внутри SVG нельзя.
- **Кадрирование:** двойной щелчок по картинке или кнопка Crop; Enter или щелчок мимо — применить, Esc — отменить.
- Большие фото и страницы PDF загружаются в фоне: пока картинка не готова, на её месте серая карточка, а программа не замирает. Сначала загружается то, что на экране. Если картинок очень много, программа держит в памяти только уменьшенные копии тех, что давно не попадали на экран, и при приближении загружает полную заново. Экспорт и печать всегда ждут все картинки в полном размере. В браузере картинки появляются по одной за кадр.
- Значок с крестом на месте картинки — файл отсутствует или не читается.

## PDF

- Перетащите файл `.pdf` в окно или выберите его в File → Insert file… — он встанет на доску книгой: видна одна страница, а листаются они на том же месте. Подходит для учебников любой длины.
- Листать: круглые кнопки со стрелками слева и справа от страницы, или выделите книгу и нажмите PageDown / PageUp, или кнопки ◀ ▶ в панели выделения. Там же номер страницы: введите число или потяните мышью, чтобы перейти сразу на нужную.
- Открытая страница сохраняется вместе с доской: после закрытия и открытия книга покажет ту же страницу. Перелистывание работает и на доске только для чтения; Ctrl+Z возвращает предыдущую страницу.
- Книгу можно двигать, масштабировать, копировать и кадрировать, как картинку; её ширина при листании не меняется, высота подстраивается под страницу.
- Страницы обведены тонкой линией, чтобы было видно, где кончается белый лист. PDF из одной страницы тоже встаёт книгой, только без кнопок листания. Страницы рисуются с запасом чёткости для приближения; следующая страница готовится заранее, так что листание вперёд мгновенное.
- Защищённые паролем PDF пока не открываются.

## Карточки ссылок

- Скопируйте веб-адрес в браузере и нажмите Ctrl+V на доске (или «Paste here» в меню по правому щелчку) — появится карточка страницы: сайт, заголовок, описание и адрес.
- Программа сама загружает начало страницы и подставляет её заголовок, описание и название сайта (нужен интернет; без него карточка остаётся с адресом). Кнопка **Update preview** на панели загружает их заново.
- Значок-цепочка на карточке открывает страницу в браузере. Двойной щелчок — изменить заголовок; изменённый заголовок при загрузке не заменяется.

## Рукописный ввод (Windows)

Распознавание почерка есть только в Windows (через Windows Ink); в Linux, macOS и браузере кнопки выдают сообщение, что оно недоступно.

Выделите нарисованные штрихи — на панели появятся:

- **To text** — распознать почерк и заменить текстом (Windows Ink, без интернета);
- **Calculate** — посчитать написанное выражение вроде `12 + 7 =`: ответ встаёт справа. Понимает `+ − × ÷ : ^ %`, скобки, `√`, `²`, `³`, `π`, десятичную запятую. Распознаватель часто путает цифры с буквами (в русской Windows — с кириллицей: «З» вместо 3, «х» вместо ×) и первым вариантом даёт не то (`/+1=` вместо `1+1=`), поэтому из всех его вариантов берётся первый, который получается посчитать. Знак «=», прочитанный как «−», тоже понимается.

Работает с пером: касание пером рисует и нажимает кнопки.

## Ссылки и якоря

- Кнопка **Link** на панели: веб-адрес (`example.com` тоже подойдёт), один из фреймов, «Pick on board» — затем щёлкнуть объект, на который будет ссылка.
- У объекта со ссылкой справа сверху значок-цепочка: щелчок открывает страницу в браузере или переносит вид к связанному объекту.
- **Copy link** (в окне Link или в меню по правому щелчку) копирует ссылку на объект; её можно вставить в Link другого объекта.

## Теги и фильтр

- Кнопка **Tags** на панели: поставить или снять теги, создать новый (поле New tag). Теги показываются цветными плашками на объектах.
- Меню **Filter**: выбрать теги и/или цвета заливки — остальное бледнеет; Show everything — сбросить. Там же кружок перекрашивает тег, × удаляет его с доски.

## Реакции

- Выделите объект → кнопка **React** на панели: «согласен» (+), «нравится» (сердце), «смешно» (улыбка), «важно» (звезда), «готово» (галочка), «внимание» (!). Повторный щелчок снимает вашу реакцию.
- Реакции видны плашками со значком и числом справа внизу (у стикера — внутри, у остальных — под объектом); ваши подсвечены цветом.
- Автор реакции — имя пользователя в системе. При копировании объекта реакции не копируются.

## Комментарии

- Инструмент «Comment» (клавиша C): щелчок по объекту или по пустому месту открывает новое обсуждение; напишите текст и нажмите Comment (или Ctrl+Enter).
- Обсуждения отмечены значками-«облачками»: у объекта — у его левого верхнего угла, на доске — в той точке. Щелчок по значку открывает обсуждение: ответы (Reply, Ctrl+Enter), Resolve — отметить решённым (значок прячется), Reopen — открыть снова, Delete — удалить обсуждение; свой комментарий можно удалить кнопкой Delete рядом с ним. × или Esc — закрыть.
- `@имя` в тексте выделяется цветом (упоминание).
- Меню **Comments** вверху — список обсуждений, щелчок переносит к нему. Show resolved — показать решённые.
- Автор — имя пользователя в системе. Обсуждение объекта прячется, пока объект удалён, и возвращается вместе с ним по Ctrl+Z.

## Поиск

Ctrl+F или Find: ищет по тексту объектов, документов, стикеров, фигур, заголовкам фреймов, подписям линий, ячейкам таблиц, карточкам и колонкам канбана, темам майнд-карт… (без учёта регистра). Enter / Shift+Enter или стрелки — следующее / предыдущее совпадение, Esc — закрыть.

## Совместная работа

Пока только локально. В интернет программа обращается только за превью карточек ссылок. Документ уже устроен как CRDT (Loro): правки разных людей одной доски будут сливаться без конфликтов, когда появится синхронизация.

## Лицензии

Используются только зависимости с разрешительными лицензиями (проверяется `cargo-deny`). Интерфейсный шрифт — Inter (SIL OFL).
